# Results files

The pipeline line generates lots of files of which only some are kept. 
These final output files are listed and shortly described in the table below. 
`{sample}` is replaced with the sample name.

## Main output files

| **File**                                                                  | **File type**  | **Description**                                                                   |
|---------------------------------------------------------------------------|----------------|-----------------------------------------------------------------------------------|
| **Alignment**                                                             | :~~:           | ~~                                                                                |
| `results/mapped_bam/whatshap_haplotag/{sample}_T.haplotagged.bam`                    | BAM            | mapped haplotagged reads                                               |
| `results/mapped_bam/whatshap_haplotag/{sample}_T.haplotagged.bam.bai`                | BAM index      | index for haplotagged reads                                            |
| **SNV & INDELs**                                                        | :~~:           | ~~                                                                                |
| `results/snv_indels/whatshap_phase/{sample}_T.phased.include.panel.vep_annotated.vcf.gz`           | compressed VCF | phased SNVs called by DeepSomatic or ClairS and annotated by VEP |
| **CNV & SV**                                                                                                    | :~~:           | ~~                                                                                             |
| `results/cnv_sv/severus_t_only/{sample}_T_all_sv.vcf`                                                          | VCF            | SVs called by Severus (tumor-only, haplotagged BAM)                                            |
| `results/cnv_sv/sniffles2/{sample}_T.include.panel.vcf.gz`                                                     | compressed VCF | SVs called by Sniffles2                                                                        |
| `results/cnv_sv/pbsv_call/{sample}_T.include.panel.vcf.gz`                                                     | compressed VCF | SVs called by PBSV                                                                             |
| `results/cnv_sv/svdb_merge/{sample}_T.vcf`                                                                     | VCF            | Merged SV calls from all three callers (Severus, Sniffles2, PBSV)                             |
| `results/cnv_sv/svdb_query/{sample}_T.vcf`                                                                     | VCF            | Merged SVs annotated with population frequencies from the SVDB population database             |
| `results/cnv_sv/cnvkit/cnvkit_vcf/{sample}_T.pathology.annotate_cnv.germline.vcf`                              | VCF            | Annotated CNV calls from CNVkit                                                                |
| `results/cnv_sv/cnvkit/cnvkit_batch/{sample}_T.cns`                                                                   | CNS            | Copy number segments from CNVkit                                                               |
| `results/cnv_sv/cnvkit/cnvkit_batch/{sample}_T.cnr`                                                            | CNR            | Copy number ratios from CNVkit                                                                 |
| **Depth of coverage**                                                     | :~~:           | ~~                                                                                |
| `results/mosdepth_bed/{sample}_T.regions.bed.gz`                          | compressed BED | median depth of coverage for each target, generated by mosdepth                   |
| `results/mosdepth_bed/{sample}_T.per-base.bed.gz`                         | compressed BED | per-base depth of coverage for each target, generated by mosdepth                 |
| **Reports**                                                               | :~~:           | ~~                                                                                |
| `results/cnv_sv/cnvkit/html_reports/{sample}_{type}.pathology.cnv_report.html`            | HTML           | CNV report generated by CNVkit                                   |
| `results/xlsx_reports/{sample}_combined_report.xlsx` | XLSX | Excel report with SNV, SV, CNV variants of interest and a Software Versions tab |
